# Campus Marketplace — FR/NFR Ownership and Evidence

The submitted PRD defines requirement intent. The product reference and active
task sources define the accepted interpretation, owners and checks. Shared
conventions and contracts remain the sources for cross-domain rules and exact
operation behavior. This map points to each requirement’s owner, earliest valid
verification and evidence home; a planned path or declaration is not proof of
implementation or acceptance.
